Red Line Impact Model (RLIM)

v0.2.0

Data dictionary and analytical documentation for the RLIM DuckDB warehouse, covering raw cadastral and transit ingestion layers alongside standardized spatial feature engineering.

bronze.parcels — Mecklenburg County Tax Parcels (Bronze)

Raw cadastral parcel boundaries ingested from gis.charlottenc.gov CountyData MapServer.

Column Type Description Values / Examples
parcel_id string Mecklenburg County Parcel Identification Number (PID). ['00101101', '00123456']
nc_pin string North Carolina permanent parcel identification number. ['00101101', '00123457']
raw_zoning string Municipal zoning classification code from county cadastral records. ['TOD-CC', 'R-3', 'UR-2']
shape_area_sqft number Official cadastral surface area in square feet calculated by county GIS engine. [19594.48, 34699.51]
calc_acreage number Calculated parcel land area in acres (shape_area_sqft / 43,560). [0.4498, 0.7966]
geom string Raw boundary geometry represented as WKT or internal spatial geometry (OGC:CRS84 / EPSG:4326). ['POLYGON ((-80.8431 35.4993, ...))']
ingest_timestamp datetime Timestamp when record entered the warehouse. ['2024-01-01T00:00:00Z', '2027-12-31T23:59:59Z']
bronze.gtfs_stops — CATS Transit Platforms & Proposed Stations (Bronze)

Station centroids aggregated from live CATS MapServer platform polygons and planned Red Line coordinates.

Column Type Description Values / Examples
stop_id string Standard station code or planned identifier. ['JWC', 'RL_DAVIDSON', 'RL_CORNELIUS']
stop_name string Public-facing transit platform or planned station name. ['JW Clay Blvd Station', 'Davidson Main & Griffith Station']
stop_lat number Latitude in WGS84 decimal degrees. [35.0, 35.6]
stop_lon number Longitude in WGS84 decimal degrees. [-81.0, -80.6]
line_name string Transit corridor or line designation. ['BL', 'BLE', 'SL', 'GL', 'Red Line']
geom string Centroid geometry point in OGC:CRS84 (Longitude, Latitude). ['POINT (-80.8431 35.4993)']
is_planned boolean Flag indicating whether the station is an active asset (FALSE) or proposed extension (TRUE). [False, True]
ingest_timestamp datetime Timestamp when record was materialized into Bronze. ['2024-01-01T00:00:00Z', '2027-12-31T23:59:59Z']
bronze.property_sales — Recorded Property Transactions (Bronze)

Historical Mecklenburg County deed recordings and sales transactions.

Column Type Description Values / Examples
sale_id string Unique deed or system transaction identifier. ['SALE_00101101', 'SALE_2024_001']
parcel_id string Foreign key referencing bronze.parcels.parcel_id. ['00101101', '00123456']
sale_date date Closing or deed recording date. ['2000-01-01', '2026-12-31']
sale_price number Nominal transaction sales price in USD. [450000.0, 550000.0]
qualified_sale_flag string Flag indicating arm's-length market qualification. ['Y', 'N']
deed_book string Mecklenburg County Register of Deeds volume book index. ['34500', '34521']
deed_page string Mecklenburg County Register of Deeds page index. ['100', '102']
ingest_timestamp datetime Ingestion timestamp. ['2024-01-01T00:00:00Z', '2027-12-31T23:59:59Z']
silver.stations_spatial — Reprojected Transit Stations (Silver)

CATS rail and proposed commuter platforms projected to North Carolina State Plane (EPSG:2264).

Column Type Description Values / Examples
station_uid string Composite unique key resolving multi-line station collisions (line_name || '_' || stop_id). ['Red Line_RL_DAVIDSON', 'BLE_JWC']
stop_id string Base stop identifier. ['RL_DAVIDSON', 'JWC']
stop_name string Full transit platform name. ['Davidson Main & Griffith Station', 'JW Clay Blvd Station']
line_name string Corridor service name. ['Red Line', 'BLE', 'BL']
is_planned boolean Status flag (TRUE for future Red Line, FALSE for active rail). [True, False]
geom_2264 string Point geometry projected into NC State Plane (EPSG:2264, US Survey Feet). ['POINT (1449621.32 542686.55)']
silver.parcels_spatial — Harmonized Parcel Hedonic & Spatial Feature Store (Silver)

Cadastral parcels with standardized zoning classifications, Euclidean distances to CBD/stations, and walkshed bands.

Column Type Description Values / Examples
parcel_id string Mecklenburg County Parcel Identifier (PID). ['00101101', '00123456']
nc_pin string North Carolina permanent PIN. ['00101101']
shape_area_sqft number Cadastral land area in square feet. [19594.48, 34699.51]
calc_acreage number Calculated acreage. [0.4498, 0.7966]
zoning_category string Harmonized land-use zoning category. ['TOD', 'SFR', 'MFR', 'OTHER_COMMERCIAL']
dist_to_cbd_ft number Euclidean distance to Charlotte CBD (Trade & Tryon) in US Survey Feet. [92083.2, 94210.5]
nearest_station_id string Station UID of the nearest transit platform. ['Red Line_RL_CORNELIUS', 'Red Line_RL_DAVIDSON']
nearest_station_name string Name of the nearest transit platform. ['Cornelius Town Center Station', 'Davidson Main & Griffith Station']
nearest_line string Corridor line of the nearest station. ['Red Line', 'BLE']
nearest_is_planned boolean Whether the nearest station is planned (Red Line) or active. [True, False]
dist_to_station_ft number Euclidean distance to nearest platform in US Survey Feet. [4820.5, 1250.0]
dist_to_station_meters number Euclidean distance to nearest platform in meters (dist_to_station_ft * 0.3048). [1469.3, 381.0]
transit_buffer_tier string Transit walkshed catchment classification. ['QUARTER_MILE_WALK', 'HALF_MILE_WALK', 'ONE_MILE_ACCESS', 'OUTSIDE_WALKSHED']
processed_timestamp datetime Timestamp when feature transformation ran. ['2024-01-01T00:00:00Z', '2027-12-31T23:59:59Z']
silver.cpi_deflator — BLS CPI Inflation Deflator Index (Silver)

Bureau of Labor Statistics annual CPI-U averages used to adjust transaction prices to real 2026 dollars.

Column Type Description Values / Examples
sale_year integer Calendar year of property transaction. [2000, 2026]
cpi_index number Annual BLS CPI-U index value (Base Year = 2026). [270.97, 333.3]
silver.sales_standardized — Standardized Real Estate Transactions (Silver)

Historical arm's-length sales deflated to real 2026 dollars with calculated real price per square foot (PPSF).

Column Type Description Values / Examples
sale_id string Unique deed transaction identifier. ['SALE_00101101']
parcel_id string Foreign key referencing silver.parcels_spatial.parcel_id. ['00101101']
sale_date date Closing or deed recording date. ['2000-01-01', '2026-12-31']
sale_year integer Calendar year of sale. [2000, 2026]
nominal_price number Recorded nominal sales price in USD. [450000.0]
real_price_2026 number Sale price standardized to 2026 purchasing power using BLS CPI-U index. [553511.46]
shape_area_sqft number Parcel cadastral footprint area in square feet. [19594.48]
ppsf_real_2026 number Real 2026 price per square foot of land area (real_price_2026 / shape_area_sqft). [28.25, 15.95]
qualified_sale_flag string Arm's-length transaction flag screening transfers < $10,000. ['Y']
processed_timestamp datetime Timestamp when standardization completed. ['2024-01-01T00:00:00Z', '2027-12-31T23:59:59Z']
